# Auralis-Tuner

Auralis-Tuner 的开源仓库与 DSH 插件集合。

## DSH Plugins

以下 DSH 插件均已完成构建、单元测试与 GitHub Release：

| 插件 | 仓库 | 说明 |
| --- | --- | --- |
| dsh-media-matrix | [Auralis-Tuner/dsh-media-matrix](https://github.com/Auralis-Tuner/dsh-media-matrix) | 跨平台媒体内容矩阵：计划、均衡、排期、导出 |
| dsh-stock-scout | [Auralis-Tuner/dsh-stock-scout](https://github.com/Auralis-Tuner/dsh-stock-scout) | 本地优先股市分析：技术指标、信号、筛选 |
| dsh-music-analyzer | [Auralis-Tuner/dsh-music-analyzer](https://github.com/Auralis-Tuner/dsh-music-analyzer) | 音乐理论分析：和弦、调性、移调、和声、BPM |
| dsh-chromatic-tuner | [Auralis-Tuner/dsh-chromatic-tuner](https://github.com/Auralis-Tuner/dsh-chromatic-tuner) | 半音调音器：频率转音名、PCM/WAV 测音、标准调弦 |
| dsh-wake-scheduler | [Auralis-Tuner/dsh-wake-scheduler](https://github.com/Auralis-Tuner/dsh-wake-scheduler) | 通用 agent 唤醒调度器 |
